# Clickarr design language

This is the specification for how Clickarr looks, moves, and responds to a remote control. It is derived from the mockups in `mockups/` and is the authority when the two disagree. Code tokens live in `ui/design` (`Tokens.kt`, `Typography.kt`, `Theme.kt`, `Focus.kt`) and must match the values here; a change to either side is a change to both.

Rendered reference sheets: [`palette.png`](palette.png) and [`type-specimen.png`](type-specimen.png), generated by `tools/sheets.js`.

## 1. Principles

**Television, not a catalog.** The default state of Clickarr is video playing full screen. Every other surface is a brief visit: an overlay that disappears, a guide you tune from, settings you leave. Chrome should feel like it is laid over the broadcast, never like the broadcast is embedded in an app.

**Ten feet, one thumb.** Everything is read from the couch and operated with a D-pad. Text is large, targets are big, focus is unmistakable, and nothing requires pointing, dragging, or typing more than a PIN.

**Dark, calm, lit by the screen.** Near-black navy backgrounds, low-contrast panels, and a single saturated blue for the thing you are on. Glow is reserved for live signals: the now-line, the progress bar, the brand mark. The video is the brightest thing in the room.

**Instant feedback, deliberate motion.** Focus moves in zero frames. Panels slide in fast and leave faster. Nothing bounces, nothing springs, nothing waits for an animation before responding to the next key.

**Familiar to anyone who has used a cable box.** Channel numbers on the left, time across the top, now-line down the middle, Up Next on the right. Clickarr earns its novelty from what it does, not from inventing new navigation.

|---|---|---|

| `bg.panel` | navy-900 | Side panels, settings nav, channel list |
| `bg.surface` | navy-800 | Overlay cards, dialogs, Up Next |
| `bg.cell` | navy-700 | Guide cells, list rows at rest |
| `bg.cellBorder` | navy-750 | 1 dp outline on cells |
| `bg.elevated` | navy-600 | Setup card, header band, hover-less emphasis |
| `accent.primary` | blue-500 | The focused item. Only one on screen at a time. Primary buttons. |
| `accent.primaryDeep` | blue-900 | Selected but not focused: active tab, current channel in a list |
| `accent.glow` | sky-400 | Now-line, progress fill, live indicators |
| `brand.gradient` | cyan-300 → blue-500 → magenta-500 | Logo screen, splash, nothing else |
| `status.ok` / `status.warn` / `status.error` | green/amber/red-400 | Dots and inline status only, never fills |
| `text.primary` | white-100 | Titles, numbers, body on dark |
| `text.secondary` | white-60 | Subtitles, timestamps, descriptions |
| `text.muted` | white-35 | Captions, dividers, disabled |
| `text.onAccent` | `#FFFFFF` | Text on `accent.primary` |
| `focus.ring` | white at 80 % | 2 dp ring, used only when fill alone is ambiguous |
| `scrim` | navy-950 at 70 % | Behind dialogs and the overlay gradient |

#### Rules

- `accent.primary` means "you are here". Never use it decoratively. If two things look focused, the system is broken.
- Status colors appear as 12 dp dots or inline text. They never fill a card or button.
- The brand gradient appears on the logo and the splash. It is not a button style, not a header style, not a divider.
- Overlay chrome over video sits on a vertical gradient from transparent to `scrim` so text stays readable over any frame.
- There is no light theme. Do not add one.

#### Contrast (WCAG 2.1, large text threshold 3:1, body 4.5:1)

| Pair | Ratio | Use |
|---|---|---|
| text.primary on bg.base | 18.1:1 | everything |
| text.secondary on bg.panel | 9.2:1 | secondary text |
| text.muted on bg.panel | 4.6:1 | captions at 18 sp and up only |
| text.onAccent on accent.primary | 4.6:1 | focused labels |
| text.primary on accent.primaryDeep | 12.9:1 | selected tab label |
| text.primary on bg.cell | 12.1:1 | guide cells |

### 2.2 Typography

**Typeface: Inter** (SIL OFL), bundled in `ui/design`. Tabular figures are enabled wherever times and channel numbers appear so columns line up. Display sizes use Inter Display if we ever add it; until then, regular Inter with tighter letter spacing on the two largest styles.

Base canvas is 1920×1080 at TV density (1 dp = 1 px at xhdpi-tv). Compose `sp` values below are used as-is; TVs do not scale text.

| Style | Size / line | Weight | Tracking | Use |
|---|---|---|---|---|
| `display.channel` | 40 / 44 | Bold | -0.5 | Channel number badge |
| `headline.program` | 34 / 40 | Bold | -0.25 | Program title in overlay, hero titles |
| `title.screen` | 26 / 32 | SemiBold | 0 | Screen titles, tab labels, settings nav |
| `title.row` | 24 / 30 | Medium | 0 | Guide cells, list rows, button labels |
| `body` | 24 / 32 | Regular | 0 | Paragraphs on setup and settings |
| `body.secondary` | 20 / 26 | Regular | 0 | Episode names, slot times, descriptions |
| `caption` | 18 / 22 | Regular | 0.1 | "Up Next", "Synced 2 minutes ago", legal |
| `label.allcaps` | 18 / 22 | SemiBold | 1.0, uppercase | Channel name next to the number ("SITCOMS"), section eyebrows |

Rules: nothing below 18 sp. Titles truncate with an ellipsis at one line in cells and rows, two lines in cards. Never justify. Never letter-space body text.

### 2.3 Spacing and grid

- Base unit **8 dp**. Half unit 4 dp allowed only inside elements (icon-to-label, badge padding).
- Scale: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 96.
- **Safe area 48 dp** on all four edges. No text or focusable element outside it. Full-bleed video and background art ignore it.
- Content column for settings and setup: 1120 dp max width, centered or left-aligned to the nav.
- Guide: channel column 200 dp (including 16 dp gutter), 30 minutes = 220 dp, row height 64 dp, cell gutter 6 dp.
- Card padding 20 dp. Row padding 16 dp horizontal, 12 dp vertical. Button padding 24 dp horizontal, 14 dp vertical.
- Vertical rhythm between stacked cards or rows: 12 dp. Between sections: 32 dp.

### 2.4 Shape

| Token | Radius | Applies to |
|---|---|---|
| `radius.cell` | 12 dp | Guide cells, list rows, inputs, tabs |
| `radius.card` | 16 dp | Cards, dialogs, settings panes, Up Next |
| `radius.badge` | 20 dp | Channel number badge, logo pill, chips |
| `radius.pill` | full | Status dots, progress bars |

Corners are always rounded; there are no square-cornered surfaces. Nested surfaces step down one level (card 16 → row inside 12).

### 2.5 Surfaces and depth

Depth is expressed by lightness, not shadow. Each layer is one step lighter than what it sits on: `bg.base` → `bg.panel` → `bg.surface` → `bg.cell`/`bg.elevated`. No drop shadows anywhere in the UI.

Glow is the only "lighting" effect: a 12 dp blur of `accent.glow` at 55 % opacity behind the now-line and the brand mark on the splash. Nothing else glows.

Over video, chrome uses `scrim` gradients rather than solid panels: bottom overlay fades from transparent at 55 % height to `scrim` at the bottom edge; top-right clock sits on a small 70 % `bg.surface` pill.

### 2.6 Iconography

**Lucide** (ISC), 2 dp stroke, round caps and joins, never filled. Sizes: 24 dp inline with `title.row`, 28 dp in tabs and settings nav, 32 dp as channel icons in the guide column, 40 dp in the channel list, 64 dp in the Up Next or empty states.

Channel icons are a curated subset the user can pick from: `tv`, `film`, `drama`, `rocket`, `smile`, `snowflake`, `music`, `trophy`, `ghost`, `heart`, `star`, `gamepad-2`, `baby`, `laugh`, `sword`, `globe`, `clapperboard`, `radio`, `flame`, `sun`. Icons inherit text color; on a focused (blue) row they are white.

Provider marks (Plex now; other media servers later) appear only on the setup screen and the Media Server settings pane, at 40 dp, unmodified, on a `bg.elevated` tile.

### 2.7 Motion

| Token | Duration | Easing | Use |
|---|---|---|---|
| `motion.instant` | 0 ms | none | Focus movement. Focus never animates position. |
| `motion.fast` | 120 ms | standard decelerate | Focus fill color, cell highlight, status change |
| `motion.enter` | 200 ms | emphasized decelerate | Overlay, mini-guide, dialogs appearing |
| `motion.exit` | 150 ms | accelerate | Anything leaving the screen |
| `motion.scroll` | 180 ms | standard | Guide horizontal shift when focus crosses the window edge |

Rules: nothing scales, bounces, or springs. Panels translate from their edge of origin (overlay from bottom, mini-guide from bottom, settings pane crossfade). Channel changes do not animate; the overlay simply updates. If the user presses a key during an animation, the animation is cut and the key is honored. Respect the system "remove animations" setting by collapsing every duration to 0.

### 2.8 Focus and the remote

The focus model is the heart of the system.

- **Exactly one focused element** at all times, and it is always visible. The cue is a solid `accent.primary` fill with `text.onAccent` text. On elements that are also selected (active tab, current channel), add the 2 dp `focus.ring` so focus and selection do not merge.
- **No scale, no shadow on focus.** The mockups show flat fill; keep it. Scale is reserved for nothing.
- **Focus never jumps unexpectedly.** Up and down move between rows; left and right move within a row. In the guide, vertical moves land on the cell overlapping the focused time, not the first cell in the row.
- **Back always goes up one level** and never exits the app without a confirmation from the player root.
- **Initial focus** on every screen is the most likely next action: the current program in the guide, the first unfinished step in setup, the first row of a list.
- **Long-press OK** opens contextual actions where they exist (favorite a channel, channel details). It is never the only way to reach something.

Key map (also in proposal section 10.6):

| Key | Player | Guide | Lists and settings |
|---|---|---|---|
| Up / Down | Channel up / down | Row up / down | Item up / down |
| Left / Right | Last channel / mini-guide | Cell left / right (scrolls window at edges) | Pane left / right, toggle values |
| OK | Toggle overlay | Tune (if now) or details | Activate |
| Back | Hide overlay, then exit prompt | Return to player | Previous pane, then previous screen |
| Play/Pause | Pause; resume re-syncs to live | Tune focused | ignored |
| Menu | Guide | Favorites filter | ignored |
| 0 to 9 | Channel entry, 2 s commit | Channel entry | ignored |
| Channel +/- | Channel up / down | Jump 5 rows | ignored |

## 3. Elements

Each element lists anatomy, variants, states, and the tokens it uses. States are: rest, focused, selected, selected+focused, disabled. There is no hover.

### Button

Anatomy: label (`title.row`), optional leading icon 24 dp, 24×14 dp padding, `radius.cell`.

| Variant | Rest | Focused | Disabled |
|---|---|---|---|
| Primary | `accent.primaryDeep` fill, `text.primary` | `accent.primary` fill, `text.onAccent` | fill at 40 %, text.muted |
| Secondary | `bg.cell` fill, 1 dp `bg.cellBorder` | `accent.primary` fill | same |
| Ghost | transparent, `text.secondary` | `accent.primary` fill | text.muted |

Minimum width 160 dp. Full-width inside cards (the "Manage Household" button in the mockup is a full-width primary).

### Channel number badge

44×44 dp minimum, grows with digits. `bg.surface` fill at rest, `radius.badge`, `display.channel` text. In the overlay and channel preview card it is standalone; in lists the number is plain text in the row.

### Channel name label

`label.allcaps` in `text.secondary`, with a 24 dp channel icon leading. Example: `[tv] SITCOMS`.

### Status dot

12 dp circle, `status.*` color, with a 2 dp `bg.panel` ring so it reads on any surface. Always paired with text that says the same thing ("Synced 2 minutes ago"); the color is reinforcement, not the message.

### Progress bar

6 dp tall, `radius.pill`. Track `text.muted` at 60 %, fill `accent.glow`. Used for program progress in the overlay. Text to the right in `body.secondary`: `17:03 / 30:00` (position within the slot, tabular figures).

### Tab

`title.screen` label with 28 dp icon above it, 16 dp padding, `radius.cell`. Rest: `text.secondary`. Selected: `accent.primaryDeep` fill, `text.primary`. Focused: `accent.primary`. Selected+focused: `accent.primary` plus `focus.ring`.

### List row

64 dp tall, `radius.cell`, 16 dp horizontal padding. Leading: number (48 dp column, `title.row`) and 40 dp icon. Label `title.row`. Optional trailing: value in `text.secondary`, chevron 24 dp, or status dot. Rest `bg.panel` (transparent on panel), focused `accent.primary`, selected `accent.primaryDeep`.

### Text field (TV)

Used only for server URL, token, PIN, and names. 64 dp tall, `bg.cell` fill, `radius.cell`, `title.row` text, placeholder in `text.muted`. Focused: 2 dp `accent.primary` border (not fill, so the text stays readable while typing). PIN entry uses six 64 dp boxes with one digit each.

### Toggle

Rendered as a row with a trailing value "On" / "Off" in `text.secondary`; Left/Right or OK flips it. No switch graphic; it reads poorly at ten feet.

### Chip

Used for filters in the channel editor (genres, decades). 40 dp tall, `radius.badge`, `caption` text. Rest `bg.cell`; selected `accent.primaryDeep`; focused `accent.primary`.

### Clock

`title.screen` in `text.primary`, tabular figures, top-right inside the safe area on every screen except the player, where it sits in a 70 % `bg.surface` pill.

## 4. Components

### Shell (top bar)

Height 96 dp inside the safe area. Left: logo pill (mark 40 dp + wordmark, `bg.surface` at 70 %, `radius.badge`). Center: tabs Guide · Channels · Favorites · Settings. Right: clock. The shell is present on Guide, Channels, Favorites, and Settings; it is not present on the player or in setup. Back from any tab returns to the player.

### Playback overlay

Appears on channel change, OK, or after returning from the guide; hides after `overlayTimeout` (default 5 s, configurable 2 to 10). Composition over a bottom scrim gradient:

```text
┌────────────────────────────────────────────────────────────────┐
│ [logo pill]                                           7:17 PM  │
│                                                                │
│                                                                │
│ [10]  [tv] SITCOMS                                             │
│ [⚙]   The Office                        ┌───────────────────┐  │
│       Dinner Party                      │ [thumb] Up Next    │  │
│       7:00 PM – 7:30 PM                 │  Parks and Rec     │  │
│       ━━━━━━━━━━━━━━━━━━━━━━━  17:03 / 30:00  │  7:30 PM – 8:00 PM │  │
└────────────────────────────────────────────────────────────────┘
```

Left block: channel badge above a settings-gear ghost button (the only focusable things on the overlay; focus starts on the badge, OK on the badge opens the guide, OK on the gear opens settings). Then channel name label, `headline.program` title, `body.secondary` episode name and slot time, progress bar. Right block: Up Next card. The progress bar reflects position in the slot, so filler time counts.

### Up Next card

`bg.surface` at 90 %, `radius.card`, 20 dp padding. Leading thumbnail 120×68 dp with `radius.cell`. "Up Next" in `caption` + `text.secondary`, title in `title.row`, slot time in `body.secondary`. Not focusable.

### Guide grid

```text
            │ 7:00 PM      7:30 PM      8:00 PM      8:30 PM
 Today      │              ┃
  5 COMEDY ⚲│ Seinfeld    ┃Seinfeld    │ Community ───────────
 10 SITCOM ▣│ The Office ▓▓▓▓▓▓▓▓▓│ Parks       │ Seinfeld  │ The Office
 20 SCI-FI ◐│ Star Trek: TNG ───────┃──────────│ Stargate SG-1 ───────
```

- **Channel column** 200 dp, sticky, `bg.panel`. Each row: number (`title.row`), name (`label.allcaps`), 32 dp icon right-aligned. The row for the channel currently playing uses `accent.primaryDeep`.
- **Time header** 40 dp, `body.secondary` labels at each 30-minute column, "Today" (or the date) in the column header. Sticky vertically.
- **Cells** `bg.cell` fill, 1 dp `bg.cellBorder`, `radius.cell`, 6 dp gutter, `title.row` label left-aligned with 12 dp padding, one line, ellipsis. Width = duration × 220/30 dp. A cell that starts before the window shows its label at the window edge (sticky label). Past cells: label at `text.muted`. Current cell: thin `accent.glow` progress along its bottom edge.
- **Now-line** 2 dp `accent.glow` with 12 dp glow, full height, redrawn each minute. The window opens at the previous half-hour boundary so the now-line is never at the very left.
- **Focus** per 2.8. Window scrolls horizontally by 30 minutes when focus crosses the right edge, and never scrolls past "now minus 30 minutes" to the left in the MVP.
- **Details** on OK for a non-current cell: a `bg.surface` card over the grid with artwork, synopsis, slot time, and a primary "Tune to channel" button.

### Mini-guide

Bottom sheet, 240 dp tall, same cells as the guide for the current channel only: now and the next three. Left/Right moves between them; OK on "now" closes it, on a future cell shows details. Enter from the right edge via `motion.enter`.

### Channel list with preview

Two panes. Left pane 480 dp `bg.panel` with a `title.screen` header ("Channels") and list rows (number, 40 dp icon, name). Right pane shows the focused channel: in Phase 1 a static card with current-program artwork, the channel badge, channel name label, thumbnail, `title.row` program title, slot time. Phase 3 adds live video after a 1 s dwell. The preview card is `bg.surface` at 90 %, `radius.card`, anchored bottom-left of the pane with 32 dp margin.

### Settings

Left nav 320 dp `bg.panel`: rows with 28 dp icons for General, Media Server, Channels, Scheduling, Household, Appearance, Playback, About. Right pane: `title.screen` header, then stacked cards (`bg.surface`, `radius.card`, 12 dp apart). Right moves into the pane, Left returns to the nav. Back from the pane returns to the nav; Back from the nav returns to the shell.

### Device card (household)

Row inside a card: 40 dp icon tile (`bg.elevated`, house icon for coordinator, monitor icon for members), name in `title.row`, status in `caption` ("This device", "Synced 2 minutes ago"), trailing status dot. The connected-household summary card at the top uses the same anatomy with a larger 56 dp tile.

### Server picker row

Setup only. 88 dp tall, `bg.panel` row on a `bg.elevated` card, 40 dp provider mark tile, provider name in `title.row`, trailing chevron. Providers that are not yet implemented show "Coming soon" in `caption` and are not focusable.

### Dialog

Centered, 640 dp wide, `bg.surface`, `radius.card`, 32 dp padding, over `scrim`. Title `title.screen`, body `body`, buttons right-aligned, primary last. Focus starts on the safe choice. Used for: exit confirmation, remove device, apply lineup now or at the boundary, PIN entry and PIN display.

### PIN display and entry

Coordinator side: a dialog with the six digits in `display.channel`, grouped 3+3, and a 120 s countdown in `caption`. Joiner side: six boxes (see Text field). Wrong PIN shakes nothing; it shows an inline `status.error` line and clears.

### Filler card

Shown between `contentEnd` and `end` of a slot and when a program cannot play. Full screen `bg.base` with the channel badge and name top-left, "Up next" block centered (title, slot time, countdown), and the reason line when applicable ("Not available on this device", "Can't reach Plex server WOPR"). No spinner; the countdown is the activity indicator.

### Toast

Bottom-center, 56 dp tall, `bg.surface` at 95 %, `radius.badge`, `body.secondary` text, 3 s, non-focusable. Used sparingly: "Added to favorites", "Household coordinator offline".

## 5. Screen templates

All at 1920×1080, 48 dp safe area. Numbers are dp.

| Screen | Structure |
|---|---|
| **Player** | Full-bleed video. Overlay per 4. Mini-guide on Left/Right. Nothing else. |
| **Guide** | Shell (96) + time header (40) + grid. Channel column 200, visible window 1624 wide ≈ 3 h 40 m. 10 rows visible at 64 + 6. |
| **Channels** | Shell + two panes: list 480, preview flex. |
| **Favorites** | Same as Guide, filtered to favorites, with an empty state card if none. |
| **Settings** | Shell + nav 320 + pane flex (max 1120 content). |
| **Setup** | No shell. Centered column 880 wide: stacked logo (mark 160 over wordmark), tagline in `title.screen`/`text.secondary`, one `bg.elevated` card per step. Background: blurred, darkened still (the mockup's living room) at 40 % over `bg.base`. |
| **Pairing** | Settings pane variant with the dialog pattern. |
| **Diagnostics** | Settings pane with a monospace block (`Roboto Mono` or system mono, 20 sp) for the airing math and log tail. The one place a monospace face is allowed. |

## 6. Content and voice

- **Calm and plain.** Sentences, not labels with colons. "Can't reach Plex server WOPR" not "Error: connection failed."
- **The user owns the TV.** "Your channels", "your library". Clickarr never says "we".
- **Times** in the device locale's short format with tabular figures: `7:00 PM – 7:30 PM`, `17:03 / 30:00`. En dash with spaces between times. 24-hour clocks follow the system setting.
- **Channel names** display as entered in lists and as uppercase in the `label.allcaps` role only. Never force case in data.
- **Numbers** right-aligned in columns. Channel numbers have no leading zeros.
- **Status lines** say what and when: "Synced 2 minutes ago", "Living Room (Coordinator)", "This device".
- **Empty states** say what to do next in one sentence and offer one button: "No channels yet. Create one from a show, a collection, or a playlist." + "Create channel".
- **Never** use exclamation marks, "Oops", or jokes in errors. Never show a stack trace outside Diagnostics.
- Strings are externalized from day one; English is the source language.

## 7. Accessibility

- Contrast per 2.1. Secondary and muted text are never used below 18 sp.
- Focus is always visible (2.8), and a focused element is never hidden under a scrim.
- Color never carries meaning alone: every status dot has text, the now-line has the clock, the current cell has a progress edge and the "now" label in details.
- Every focusable element has a content description for TalkBack that includes its role and state: "Channel 10, Sitcoms, selected".
- Text does not scale on TV, but layouts must survive 1.3× anyway for the future and for long translations: cells ellipsize, rows wrap values to a second line, buttons grow.
- Motion respects the system reduce-animations setting (2.7).
- No flashing content. The now-line glow is static.
- Audio: channel changes produce no sound effect; the broadcast is the sound.

## 8. Brand in the app

- The mark appears in the shell logo pill (40 dp) and on the setup screen (160 dp). It is not a watermark on video and not a background texture.
- The wordmark is never set in a different face. Use `brand/svg/wordmark.svg` (outlined) or the horizontal lockup; do not type "Clickarr" in Inter Bold and call it the logo.
- The brand gradient is the mark's screen and nothing else in the UI.
- Launcher icon and TV banner come from `brand/android/`; the splash is `bg.base` with the stacked lockup centered, no animation.
- Provider marks follow their owners' guidelines, unmodified, on a neutral tile.

## 10. Governance

- **This file is the spec.** Mockups are direction. If a mockup and this file disagree, this file wins; if this file is wrong, change it in the same PR as the code.
- **Tokens change here first.** A new color, size, or motion value is added to section 2 and to `ui/design` together. Feature modules never define their own colors or sizes.
- **New components** get a section 4 entry before or with their first use: anatomy, states, tokens, when not to use it.
- **Deprecation** is explicit: mark the component "Deprecated, use X" here and in a `@Deprecated` annotation in code, remove after one release.
- **Review checklist for UI PRs:** one focused element, visible on every screen; nothing outside the safe area; no text under 18 sp; no base colors in feature code; strings externalized; Back behavior matches 2.8; works on a 2018 Fire TV Stick 4K.
- **Owner:** the maintainer, until there is a second regular UI contributor; then a two-person review for anything in sections 2 and 3.
